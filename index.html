执行摘要

本研究聚焦主流 AI 平台上开发者如何获得收入、承担成本并实现商业化，比较 API 应用、平台内应用市场、积分型机器人市场、企业交付和开源衍生服务五类盈利模式。核心问题是：开发者的钱从哪里来、平台如何收费或分成，以及平台的定价和分发规则如何影响开发者利润。

收入来源开发者主要通过自有产品订阅、按次收费、企业项目、实施与运维、模板销售、广告线索和开源衍生服务获得收入。
成本与利润Token、模型调用、算力、部署、获客、合规和售后是主要成本。API 模式下平台通常先从上游收取费用，开发者再自行承担下游经营风险。
平台分成只有掌握支付结算、担保交易、广告或积分体系的平台，才具备稳定分配开发者收入的能力；流量和分发确定性往往比名义分成比例更重要。

3第三部分：学术化总结

本节从八家主体平台与三家对照平台的实证材料中，提炼五个跨模式的共同机制。核心命题是：AI 平台的开发者盈利模式，本质上不是"平台如何分配收益"的问题，而是"平台是否具备观测下游交易的技术能力，以及它是否选择行使这一能力"的问题。观测能力决定分成可能性，而是否行使则由平台在"生态规模最大化"与"当期利润最大化"之间的权衡决定。

3.1　纵向定价关系：一个被压缩至负值的中间层

命题一：平台 API 价格与开发者应用零售价之间，不存在稳定的加成率结构，因为中间层的毛利已被竞争压至零附近。

传统平台经济学中，上游要素价格 c 与下游零售价 p 之间通过双重加成（double marginalization）联系，平台的定价权体现在其对 c 的控制。但 AI 平台的实证材料显示了一个不同的结构：

智谱招股书（经审计，2025H1）：
  云端 MaaS 部署毛利率 = −0.4%　（2024 年为 +3.4%）
  本地化私有部署毛利率 = +59.1%　（2024 年为 +66.0%）

IDC（2025 全年，中国公有云 MaaS）：
  全市场 token 调用量 = 1,944 万亿 tokens　　全市场营收 = 30.7 亿元
  → 隐含单价 ≈ 1.6 元 / 亿 tokens

这两组数字共同表明：API 批发（"API 应用模式"的平台侧）在中国市场已不是一门有毛利的生意。价格的下行不是市场出清的结果，而是竞争性定价（competitive pricing）叠加自研芯片、缓存技术、MoE 并行等成本侧创新共同作用的结果——火山 2024-05 将 doubao-pro-32k 定至 0.0008 元/千 token（自称较同业低 99.3%）触发行业降价潮，2025-06 豆包 1.6 进一步取消能力分档、改按输入长度分档，综合成本再降 63%；百度以主动 Cache 模式宣称降推理成本 80%；阿里的显式缓存命中价为标准输入价的 10%，且明确规定缓存折扣与 Batch 折扣不可叠加——后者是平台在极低价格下守住成本底线的技术性防御。

其直接推论是：开发者应用的零售价与平台 API 价格之间的关系，从"成本加成"退化为"成本无关"。当 token 成本占开发者可变成本的比例降至个位数百分比时，开发者的定价锚点转向价值定价（value-based pricing）而非成本定价。百度千帆产品负责人张婷的表述精确捕捉了这一转变："计费方式可能从'按词元数'演变成'按任务结果'……某电商客户不关心每次对话消耗了多少词元，只关心解决了多少客诉、节省了多少人工成本。"其"蒂彩工艺"案例中，客户付费依据是"30 秒完成 3 小时的工作"，效率提升 360 倍——定价锚点从投入侧（token）迁移至产出侧（任务结果）。

唯一的例外是 Poe：由于平台兜底全部推理成本，创作者的 price per message 是纯粹的价值定价，与底层 token 成本完全解耦。Poe 因此提供了一个"零成本约束下的开发者定价行为"的天然实验：即便在此条件下，平台仍设置了每千条消息 $10,000 的上限，并以"高价影响分发"作为软约束——说明平台对下游价格的干预动机，并不来源于成本传导，而来源于对用户体验与生态健康的治理需求。

3.2　成本承担：三种截然不同的算力责任分配

命题二：模型调用与算力成本的承担方式，将平台分为三种制度类型，且该类型与平台能否抽成严格对应。

类型算力成本承担方代表平台抽成可能性
I. 开发者自担开发者向平台购买 token，全部推理成本内化为开发者成本OpenAI、Anthropic、DeepSeek、百炼、方舟、千帆、BigModel、OpenRouter无法抽成——平台已在上游完成价值捕获，且无法观测下游交易
II. 平台兜底平台承担全部模型推理成本（含自带模型的协商覆盖）与基础设施Poe（唯一）必然抽成——平台已垫付成本，必须通过用户端定价回收，抽成是结构性必需
III. 平台全担且不分配平台承担全部成本，创作者零成本、零收入Character.AI不抽成也不分成——价值 100% 归平台

类型 I 的关键性质是：平台在开发者付费购买 token 的瞬间就已完成全部价值捕获。此后开发者赚多少，与平台无关，平台也无从知晓。这解释了一个反复出现的现象——类型 I 平台的官方文档中普遍不存在分成条款，且这一"缺席"是结构性的而非疏漏：Anthropic 商用条款全文无分成字段；OpenAI Apps SDK 货币化文档推荐 external checkout 并明确"payment, billing, taxes, refunds, and compliance are handled entirely on your domain"；DeepSeek License FAQ 更是明示"不会主张开发者获得的任何收益"。

"不抽成"与"不结算"是同一枚硬币的两面。OpenAI 选择让开发者在自有域名完成结算，就等于选择放弃观测能力，也就等于选择放弃抽成能力。反之，扣子模板商店之所以能够分账，正因为它建立了"抖音支付商户通 + 虚拟在途账户 + 7 天担保期"的完整结算链路——先有结算权，才有分成权。

值得注意的是 Anthropic 的反向分成：其 15–20% 的 ARR 经 AWS Bedrock 等间接渠道产生，需向云厂商支付约 20% 渠道分成 ②。这提示了一个常被忽视的事实——在多层分销的 AI 供应链中，模型厂商自身也可能是"向平台付费"的一方，平台角色是相对的而非绝对的。

3.3　平台如何参与收益分配：四种工具及其可观测性排序

命题三：平台参与开发者收益分配的四种工具（佣金、流量、积分、结算规则）在"可观测性"上呈严格递减，而平台对工具的选择恰与其不愿被观测的程度正相关。

工具典型实例可观测性制度性质
显式佣金百度云市场 ≥10%；OpenRouter 充值费 5.5%、BYOK 5%；Perplexity 返还出版方 80%高（公开百分比）契约化、可核算、可诉讼
流量分配百度搜索智能体分发（广告分成/线索转化）；Anthropic Claude Marketplace 将企业承诺额度导向伙伴；OpenAI "达到更高设计标准的应用可获更高曝光"中（规则公开、权重不公开）裁量性、不可诉、事后可撤回
积分定价Poe：$30/百万点由平台单方设定；2025-07 至 2026-08 各档积分额度静默下调 34%低（兑换率公开、抽成隐含）货币发行权；可在名义价格不变下改变实际单价
结算规则扣子"7 天在途 + 预设比例"（比例不公开）；Poe "月末后 30–45 天 + $10 门槛 + 23 国限制"；OpenAI ACP "small fee"（未量化）最低（比例与时点均不公开）现金流占用 + 沉默抽成 + 地域排除

本研究最值得注意的实证发现是：拥有真实分成机制的平台，恰恰是最不愿公布分成比例的平台。Poe 有真实的现金分成（官方承认"支付给头部创作者每年数十万美元"），却从未公布分成百分比；扣子有完整的自动分账链路，官方文档却仅表述为"预设的比例"；OpenAI 的 ACP 仅称 "small fee"。反之，明确声明不加价的 OpenRouter 与 Hugging Face 却把费率写得一清二楚。

这构成一个透明度悖论：费率的公开程度与平台从该费率中获利的程度呈负相关。其机制并不神秘——公开费率意味着接受横向比较与舆论约束，而隐含抽成允许平台在不引发集体反应的前提下持续调整。Poe 在 13 个月内将各档积分额度下调 34% 而未发布任何公告，是这一机制最清晰的实证。

Perplexity Comet Plus 公开"80% 返还出版方"的做法，恰恰证明了公开分成比例在技术与商业上完全可行。因此，Poe 与扣子的不公开是策略选择而非结构约束。

3.4　定价权与治理权：名义自由与实质约束的分离

命题四：开发者的定价权在名义上普遍完整，但其实际行使受到"分发惩罚"这一非价格治理工具的系统性约束；定价权与治理权不是零和的，而是分层的。

观察八家平台的定价权配置，可以看到一个高度一致的模式：几乎没有平台明文限制开发者的终端定价。Anthropic 商用条款无定价限制；DeepSeek 明示不主张任何收益；OpenAI 官方文档写明"developers are responsible for choosing how to monetize"；智谱、百炼同样不干预。

但"不限制价格"不等于"不影响价格"。Poe 提供了最精确的样本，其规则包含三层：

  1. 硬性上限：每 1,000 条消息 $10,000——这是明文的、可核查的价格天花板
  2. 软性惩罚："高价与频繁改价会影响你在 Poe 上的分发"——这是非价格的、裁量性的、不可申诉的约束
  3. 信息不对称：用户看到的是 "your price + our costs" 的聚合积分值，创作者无法观测该聚合过程，因而无法准确预判自己的定价对用户实际支付的影响

第 2 层是关键。分发权是比定价权更高阶的权力：定价权决定单笔交易的分配，分发权决定交易是否发生。当平台同时掌握"允许你自由定价"与"根据你的定价决定是否给你流量"两项权力时，名义定价自由在实质上被转化为平台偏好的自我实现。OpenAI 的表述结构完全相同——"符合开发者指南的应用均具备上架资格，而设计与功能方面达到更高标准的应用，则可在目录和对话中获得更高的曝光"，标准的定义权与判定权均在平台。

百度是这一逻辑的极端形态：其开发者变现完全依赖广告分成与线索转化，单价由百度广告/线索体系而非开发者设定。开发者事实上放弃了定价权，换取的是百度搜索"每天几十亿次请求"的分发池——即用定价权交换获客成本的外部化。这是本研究中唯一明确的"定价权—获客成本"交换案例，也解释了为何百度选择流量分成而非交易抽佣：当平台承担了获客，它就有理由分享收入；当平台只提供 token，它就没有。

一个重要的制度外生冲击是：2026 年 7 月，豆包与千问在同一窗口（7 月 10–15 日）下线 C 端用户自建智能体，背景为《人工智能拟人化互动服务管理暂行办法》2026-07-15 施行。这表明在中国市场，平台治理权之上还存在监管治理权，开发者的分发通道可以被第三方规则整体关闭——两家头部平台的 C 端智能体分发通道同时消失，开发者分发重心被迫回退至 B 端与工具侧（扣子、飞书、抖音；百炼 API/云市场）。这是"平台风险"之上的"制度风险"，在任何以美国平台为样本的研究中都不会出现。

3.5　开发者进入、应用质量与生态规模：分成不是充分条件，也不是必要条件

命题五：开发者进入规模与平台分成机制之间不存在稳定的正相关；决定进入的是"分发确定性 × 成本可承受性"，而非"收益分配比例"。

如果分成是开发者进入的驱动力，我们应观察到：有分成的平台开发者更多。实证材料给出了相反的图景：

Character.AI 是最锋利的反例：它拥有海量 UGC 创作者，却提供零现金分成，2026-06 推出的创作者工具全套仅为曝光与数据看板（Leaderboards、Insights、Following Tab），Charms 虚拟货币也是面向用户而非创作者。这说明在内容创作类场景中，声誉、社群地位与自我表达可以完全替代货币激励。

与之对称的是 Hugging Face：对模型作者零分成，却拥有 2M+ 模型与 13M 用户。其官方披露的分布数据尤其重要——Top 200 模型（占全站 0.01%）吃掉 49.6% 的全站下载，约一半模型的总下载量不足 200 次。这是本研究中唯一公开的开发者收益（此处为注意力）分布数据，其形态是典型的幂律分布。

将该分布与 Poe 的官方表述并置，可以得到一个重要推论：Poe 称"支付给头部创作者每年数十万美元"——刻意的单数表述本身暗示了极端的收益集中。若中位创作者收入可观，平台的宣传激励会促使其公布均值或中位数；选择只公布头部单点，正说明分布高度偏斜。因此，可以合理推断（但不可作为事实断言）：积分型市场的创作者收益分布，与 Hugging Face 的下载量分布同构——幂律、长尾、中位数接近于零。

那么什么决定了开发者进入？实证材料指向两个变量的乘积：

开发者进入意愿 ≈ 分发确定性 × 成本可承受性

· 分发确定性：OpenAI 9 亿周活 / 百度搜索几十亿次日请求 / 抖音生态——平台自带的、开发者无法自建的用户触达
· 成本可承受性：智谱 GLM-4-Flash 免费、火山限时千万 token 包、百炼 90 天 100 万 token 免费额度、Poe 平台全额兜底——把首次尝试的边际成本压至零

收益分配比例，在这个函数中是三阶变量。

这也解释了中国平台普遍采取的"免费额度 + 开源权重 + 补贴基金"组合（智谱 Z 计划 10 亿元基金 + 开源基金 1,000 万现金 + 1,000 亿 tokens；火山模型券；百炼 90 天免费额度）：这些都是在降低进入成本，而非提高收益分配。平台的隐含判断是：开发者的进入弹性对成本远高于对收益。

最后，关于应用质量与生态规模的关系，GPT Store 的历史提供了一个负面教训：2024 年初 GPT Store 以零门槛换取数量，结果陷入低质泛滥；2025-10 的 Apps SDK 则反转策略——要求实名验证、服务器验证、功能测试、审核前置、年龄分级，用准入门槛换质量。OpenAI 官方明确"符合指南的应用均可上架，达到更高设计与功能标准的应用可获更高曝光"，即用分发权而非准入权做质量分级。这是从"App Store 式的准入治理"向"推荐算法式的曝光治理"的迁移，也再次印证了命题四：在 AI 平台上，分发权是比准入权更精细、也更强大的治理工具。

3.6　综合：一个关于"观测能力"的统一解释

把五个命题合并，可以得到一个统一的解释框架：

  1. AI 平台的默认状态是"不分成"，因为 API 应用模式下平台已在上游完成价值捕获，且下游交易发生在平台视野之外（命题二）。八家主体平台中，六家不存在任何形式的应用收益分成。
  2. 分成的前提是结算权，结算权的前提是观测能力。扣子建立了担保交易链路才有分账；百度建立了广告与线索计费系统才有流量分成；Poe 发行了内部货币才有隐含抽成。OpenAI 选择 external checkout，就等于选择放弃这三者（命题三）。
  3. 一旦平台获得观测能力，它同时获得的是不透明的定价权。积分制、担保期、结算周期、地域限制——这些工具的共同特征是把可核算的百分比转换为不可核算的规则。费率的公开程度与获利程度负相关（命题三的透明度悖论）。
  4. 开发者的定价权在名义上完整，但被分发权实质性约束。价格上限、"高价影响分发"、"更高标准获更高曝光"——平台不需要限制价格，只需要保留决定谁被看见的权力（命题四）。
  5. 而这一切对开发者进入规模的影响，远小于免费额度与流量池的影响。Character.AI 与 Hugging Face 证明零分成不阻碍供给；智谱的 4,500 万注册 / 15 万付费（0.33% 转化）证明进入门槛的降低比收益承诺更有效（命题五）。

因此，本研究的核心结论是：AI 平台开发者生态的治理，正在从"分配问题"迁移为"可见性问题"。在 token 价格趋零、中间层毛利被压至负值的市场结构下（命题一，智谱云端毛利率 −0.4%），平台已无法从开发者的交易中获取有意义的抽成收入；它真正稀缺且可垄断的资源，是用户注意力的分配权。这解释了为何 OpenAI 在 2026 年转向广告（CPM $60 起、6 周年化超 1 亿美元）、百度以搜索流量池换取开发者定价权让渡、Poe 以分发惩罚约束定价行为——当中间层不再产生利润，平台的收益就必须从"交易的一个百分比"转向"注意力的直接货币化"。开发者在这一结构中的位置，也相应地从"平台的付费客户"转变为"平台注意力供给链上的内容生产者"。
